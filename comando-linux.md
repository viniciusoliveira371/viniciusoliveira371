# Comandos básicos do Linux

Este documento reúne os comandos Linux que estou aprendendo durante meus estudos de Tecnologia da Informação.

## Comandos que pratiquei

- pwd — mostra o caminho da pasta atual.
- ls — lista arquivos e pastas.
- cd — permite entrar ou mudar de pasta.
- mkdir — cria uma pasta.
- echo — exibe uma mensagem no terminal.

## Objetivo

Aprender Linux e desenvolver conhecimentos práticos para trabalhar com Suporte Técnico / Help Desk.
